# DUYO Content

She'r, ertak, dars yordami kutubxonasi. TZ §9 ga muvofiq.

## Struktura

```
duyo-content/
├── poems/           # She'rlar (yosh va tilga ko'ra)
│   ├── uz/          # 150 ta o'zbek she'r (target)
│   ├── ru/          # 80 ta rus she'r (target)
│   └── en/          # 80 ta ingliz she'r (target)
├── stories/         # Ertaklar
│   ├── uz/          # 50 ta o'zbek ertak (target)
│   ├── ru/          # 30 ta rus ertak (target)
│   └── en/          # 30 ta ingliz ertak (target)
└── lessons/         # Dars yordami materiallari
    ├── junior/      # 7-10 yosh
    ├── explorer/    # 11-13 yosh
    └── companion/   # 14-16 yosh (DTM, IELTS)
```

## Litsenziya strategiyasi (Concept §9.2)

### Birinchi 6 oy — Safe content only

- 100% public domain content
- Folk va xalq ertaklari (anonim)
- DUYO original content

### 6-12 oy — Litsenziya negotiating

Mualliflari bilan kelishuv:
- Quddus Muhammadiy
- Tursunboy Adashboyev
- Erkin Vohidov
- Abdulla Oripov
- Чуковский, Маршак, Пушкин

### Original content production

- 10-15 zamonaviy yozuvchi kontrakt
- Har biri 20-30 she'r/ertak
- Audio versiyalar (DUYO ovozida)
- Budget: $30-50K

## Fayl formati

Har poem/story alohida `.md` fayl:

```markdown
---
id: pm-uz-001
title: "She'r nomi"
author: "Muallif"
language: uz
age_segment: [junior, explorer]  # mos yosh segmentlari
license: public_domain  # public_domain | licensed | original_duyo
audio_url: null  # mavjud bo'lganda
duration_seconds: null
tags: [folklore, nature]
---

# She'r nomi

She'r matni shu yerda...
```

## Hozir nima qilinishi kerak

1. **Public domain inventar tuzish** — qaysi mualliflarning asarlari 70+ yil oldin yozilgan
2. **10 ta yozuvchi bilan kontakt** — original content production uchun
3. **Litsenziya advokat topish** — meros olganlar bilan negotiation
4. **Voice acter tanlash** — DUYO ovozi (brand qarori)
